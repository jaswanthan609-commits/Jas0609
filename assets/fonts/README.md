Put caption fonts here (or install them system-wide). Tamil and Hindi need fonts that can
shape those scripts, otherwise captions render as boxes:

- Noto Sans Tamil: https://fonts.google.com/noto/specimen/Noto+Sans+Tamil
- Noto Sans Devanagari: https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari
- Noto Sans (English): https://fonts.google.com/noto/specimen/Noto+Sans

On Ubuntu/Debian: `sudo apt install fonts-noto-core` covers all three.
